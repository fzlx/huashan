# 二分法算法示例 (Binary Search Algorithm Examples)

这个项目包含了多种二分法算法的实现和应用示例，展示了二分法在不同场景下的使用。

## 文件说明

### 1. `binary_search.py` - 完整的二分法实现集合
包含多种二分法算法的实现：
- **基础二分查找**（迭代版本和递归版本）
- **查找插入位置**
- **查找第一次和最后一次出现位置**
- **范围查找**
- **浮点数二分法**
- **平方根计算**
- **性能测试**

### 2. `simple_binary_search.py` - 简化版演示
提供了带详细步骤说明的二分查找演示，适合学习和理解算法过程。

## 算法特点

### 时间复杂度
- **O(log n)** - 每次搜索都将问题规模减半

### 空间复杂度
- **迭代版本**: O(1)
- **递归版本**: O(log n) - 由于递归调用栈

### 前提条件
- 数组必须是**已排序**的

## 核心思想

二分法的核心思想是"分而治之"：
1. 找到数组的中间位置
2. 比较中间元素与目标值
3. 根据比较结果决定在左半部分还是右半部分继续查找
4. 重复此过程直到找到目标值或确定不存在

## 运行示例

```bash
# 运行完整的二分法示例
python3 binary_search.py

# 运行简化版演示
python3 simple_binary_search.py
```

## 算法实现要点

### 1. 防止整数溢出
```python
mid = left + (right - left) // 2  # 推荐
# 而不是 mid = (left + right) // 2
```

### 2. 边界条件处理
- 注意 `left <= right` vs `left < right` 的使用场景
- 正确更新 `left` 和 `right` 的值

### 3. 变种算法
- **查找第一次出现**: 找到目标后继续在左半部分查找
- **查找最后一次出现**: 找到目标后继续在右半部分查找
- **查找插入位置**: 适用于需要维护排序顺序的场景
